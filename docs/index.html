近いスタイル

しくみ：OpenAI の CLIP（ViT-B/32）を C++ で書き直して WebAssembly にしたものが、写真と「おしゃれな服装の写真」「だらしない服装の写真」という言葉のどちらに近いかを比べています。スタイルも同じように、写真に一番近い言葉を選んでいます。

全身が写っていて、人が大きく写っている写真のほうが当たりやすいです。点数は AI の感想で、正解ではありません。背景や写真の撮り方にも影響されます。
